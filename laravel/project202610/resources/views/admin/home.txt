middleware(2026.11.04)
1.修改config/session.php
    將'expire_on_close' => env('SESSION_EXPIRE_ON_CLOSE', false),
    改為 'expire_on_close' => env('SESSION_EXPIRE_ON_CLOSE', true),
2.建立middleware: php artisan make:middleware XXX
    例如 php artisan make:middleware CheckManager
    會在app/Http下新增一個Middleware資料夾,並在資料夾中生成CheckManager.php
3.編輯CheckManager.php
4.開啟app/bootstrap/app.php
  ->withMiddleware(function (Middleware $middleware): void {
        // 在這裡加上CheckManager, "manager":路由中會用到的名稱, 用manager代表CheckManager.php
        $middleware->alias(["manager" => CheckManager::class]);
    })
5.開啟路由routes/web.php, 將後台的路由加上middleware("manager")
